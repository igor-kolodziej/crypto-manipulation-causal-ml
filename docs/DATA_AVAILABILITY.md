# Data availability

The research dataset is not included in this repository.

It combined Telegram messages, channel/event labels, high-frequency market observations, and asset metadata. Publishing the raw material would expose user-generated content and channel identifiers and may conflict with platform terms, research-ethics expectations, and third-party data rights.

The repository therefore provides:

- an explicit event-level schema;
- deterministic synthetic fixtures;
- aggregate thesis tables and figures; and
- analysis interfaces that can be applied to a lawfully obtained dataset with the same schema.

The synthetic data does not model real people, channels, coins, or trades and must not be used to infer the thesis estimates.
