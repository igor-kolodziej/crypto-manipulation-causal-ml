# Ethics and responsible use

- The repository does not publish Telegram messages, usernames, channel identifiers, target-coin labels, or raw market extracts.
- The code is intended for research into manipulation detection and market integrity. It must not be used to coordinate trades or optimize manipulative campaigns.
- Short-horizon crypto returns are noisy, and observational causal estimates rely on strong assumptions. Results must not be treated as investment recommendations.
- Any application to new data should include a lawful-basis, platform-terms, privacy, and research-ethics review.
